# 用边界突破验证图表形态

## R — 来源

第 5.1–5.5 节，图 34–46。头肩形态的讨论强调等待突破确认。

## I — 方法

先找此前的趋势和反复交锋的价格边界，再问哪一侧越来越难以推进。不同形态可以呈现相似的轮廓，区别常在回调深度、接近边界的方向，以及突破发生在哪一侧。把候选形态、越界、回测和后续走势按时点分别记录，图的右侧只用于评价先前判断。

## A1 — 原书案例

图 46 的横盘同时具备多个顶部和底部。价格最终越过上缘，又回到原上缘测试，之后才延续上涨。看到多次遇阻时，下破与上破仍是两条待观察路径。将前三次触顶直接当作已成立的顶部，会漏掉该例实际出现的上破。

## A2 — 何时调用

适用于“这个头肩顶成立了吗”“这是反转楔形还是中继”“如何区分三重顶和上升三角形”。只需解释一根针形线时用 K 线卡；只想比较两个推进波时用波段卡。

## E — 执行与交付

1. 取同周期价格图或有序摆点，明确观察截止、此前趋势、峰谷及横向或斜向边界。用所选摆点说明画线依据，关键点不足则给出仍需观察的位置。
2. 按下表核对几何条件和触发点。

| 候选 | 先观察 | 转为已触发的证据 |
|---|---|---|
| 头肩顶／底 | 原趋势中头部刷新极值，右肩无法刷新，连接两段回撤的端点得到颈线 | 右肩形成后突破颈线；顶向下、底向上。回测另记 |
| 杯柄 | 上涨中回调，杯底由逐步走低转为抬高，接近旧高时有较短的柄部回撤 | 向上突破柄部 |
| 上升三角形 | 一再抵达相近高点，各次回调的低点抬高 | 收盘到上边界外。单次上影越界仍需核对收盘 |
| 楔形 | 两边收敛，顺楔方向的新高或新低越来越勉强 | 逆楔方向突破。楔形位于主趋势末端时可提示反转；位于逆主趋势的修正腿时可提示原趋势延续 |
| 双／三重顶底 | 多次挑战相近极值失败，标出中间回撤边界 | 顶部向下突破形成新低，底部向上突破形成新高。仅有重复触点时继续保留两种方向 |

3. 若突破后返回边界，单记回测的方向和结果。守住新一侧可以支持原解释；返回区间并继续推进，记录突破失利。未回测时只写“尚未观察到回测”。
4. 输出“原趋势｜候选和锚点｜触发边界｜已发生事件及截止｜相反证据／下一观察”。书中只对部分形态明确写到收盘越界。使用固定收盘确认、误差带或持续柱数时，写清这是本次复盘约定。

## B — 边界

小头、弱肩或不对称并不会自动排除头肩，但必须能说明从创新极值到推进失败、再到破线的顺序。孤立轮廓无法判明楔形相对主趋势的位置。书中图例无法给出普适胜率、目标价或突破后的必然方向。
