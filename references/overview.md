# Trading: Technical Analysis Masterclass — 整书理解

Rolf Schlotmann 与 Moritz Czubatinski，2019。书目信息依据英文版书名页与版权页。图号和小节号可跨阅读器回查。

收盘价相对前高或区间边界的位置，能帮助判断一次推进有没有守住所取得的进展。全书把这个问题从一根蜡烛扩展到一段行情。

1. 第 1–2 章界定交易周期、技术分析与群体行为解释。不同持有周期改变了图中“一波”的意义。
2. 第 3 章用实体、影线及其相对位置解释一次推进留下了多少成果。同一组开高低收可以来自不同的盘中路径。
3. 第 4–5 章把蜡烛组合成推进与回撤，再用高低点解释形态。一个新高还能同时伴随波段缩短，创新高和动量变弱可以共存。
4. 第 6 章把观察放回具体位置。多次受阻、反弹变弱以及越界后迅速退回，支持不同的解释。
5. 第 7 章用派生指标检查趋势、动量或波动。第 8 章提供后续学习入口，书中没有展开所链接的十步课程。

**解释边界**：作者常用买卖兴趣、订单吸收与被套者平仓来解释图例。OHLC 可检验价格是否越界、收回及延伸，无法识别交易者身份或真实挂单余额。精选历史图支持读图演练；缺少预先冻结的判据、完整失败样本和交易成本时，无法从这些图得到样本外胜率。第 2 章转述的研究亦不能替代对本书每一组规则的独立检验。

## 读图任务与交付物

|任务|来源|交付物|漏判后果|
|---|---|---|---|
|解读单根与组合 K 线|§3.1–3.6|从 OHLC 比较实体、影线、比例和实体位置，判断拒绝的方向与背景|避免只凭蜡烛颜色或名称判断反转|
|标注波段和市场阶段|§4.1–4.4|用推进、回撤和摆动高低点解释趋势是否仍完整|把力度减弱与结构破坏分开|
|检验价格形态及完成条件|§5.1–5.5|用波段、颈线或整理边界检验头肩、杯柄、三角、楔形和多重顶底|同一楔形在不同父级趋势中可有相反含义|
|画趋势线与水平支撑阻力|§6.1–6.2|核对锚点、触碰反应和角色互换，标出水平区与斜线的有效边界|防止迁就右侧走势重画线|
|筛选供需区并审阅回访|§6.3|核对离开前的窄幅停顿、离开的力度及首次回访表现|区分从起涨起跌处识别的区域和反复触碰的水平位|
|判读突破与价格陷阱|§6.4|逐根回放刺穿、收盘和后续结构，判断哪一侧的突破失去支持|保留未收盘及已确认后失败两个不同状态|
|依市场阶段解释均线|§7.1、7.2|选取 SMA 或 EMA 的周期，审阅斜率、交叉、动态支阻及价格偏离|均线滞后，盘整时反复交叉会误导|
|核对 RSI 与随机指标的动量证据|§7.3–7.4|辨认极值、背离与区间收盘位置，追踪价格确认|同类读数不能重复计为确认|
|用布林带或 MACD 检验趋势|§7.5–7.7|区分沿轨、拒绝和动能衰减，核对零轴及信号线交叉的含义|拆开收于带外与刺穿收回，识别均线证据重复|
