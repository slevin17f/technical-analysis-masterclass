# 决策规则速查 — Trading: Technical Analysis Masterclass

| 能力 | 一句话规则 |
|---|---|
| 解读单根与组合 K 线 | 从 OHLC 比较实体、影线、比例和实体位置，判断拒绝的方向与背景 |
| 标注波段和市场阶段 | 用推进、回撤和摆动高低点解释趋势是否仍完整 |
| 检验价格形态及完成条件 | 用波段、颈线或整理边界检验头肩、杯柄、三角、楔形和多重顶底 |
| 画趋势线与水平支撑阻力 | 核对锚点、触碰反应和角色互换，标出水平区与斜线的有效边界 |
| 筛选供需区并审阅回访 | 核对离开前的窄幅停顿、离开的力度及首次回访表现 |
| 判读突破与价格陷阱 | 逐根回放刺穿、收盘和后续结构，判断哪一侧的突破失去支持 |
| 依市场阶段解释均线 | 选取 SMA 或 EMA 的周期，审阅斜率、交叉、动态支阻及价格偏离 |
| 核对 RSI 与随机指标的动量证据 | 辨认极值、背离与区间收盘位置，追踪价格确认 |
| 用布林带或 MACD 检验趋势 | 区分沿轨、拒绝和动能衰减，核对零轴及信号线交叉的含义 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
