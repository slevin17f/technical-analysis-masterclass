# Technical Analysis Masterclass

用于历史价格图表复盘的中文 Codex Skill。提供图表或按时间排序的 OHLC 数据，注明周期和复盘截止点，即可检查 K 线、波段、图表形态、支撑阻力、供需区、突破陷阱与技术指标。每张能力卡标明来源章节、判断依据和仍待确认的条件。

方法来源为 Rolf Schlotmann 与 Moritz Czubatinski 合著的 *Trading: Technical Analysis Masterclass — Master the Financial Markets*（2019）。本项目使用仓颉工具独立整理为中文复盘流程。

## 安装到 Codex

在 macOS 或 Linux 终端运行以下命令。Skill 全部由 Markdown 组成，无需运行时依赖。

```sh
mkdir -p ~/.codex/skills
git clone https://github.com/slevin17f/technical-analysis-masterclass.git ~/.codex/skills/technical-analysis-masterclass
```

开启新会话，附上历史图表并输入：

> 用 $technical-analysis-masterclass 复盘这张日线图。截至最后一根已收盘 K 线，价格三次测试阻力。请区分盘中越界、收盘突破与后续收回，说明哪种情形已经发生。
